# Lyric

任务栏歌词的**显示程序**。托盘常驻，把当前播放歌曲的歌词画在任务栏里。

- **歌曲来源**：Windows SMTC（系统媒体控制）。凡是会出现在系统「媒体面板」里的播放器都能识别——QQ 音乐、网易云音乐、Spotify、浏览器、抖音等，不需要针对每个软件做适配。
- **歌词来源**：网易云音乐 / [LRCLIB](https://lrclib.net) 两套公开 API，按「歌名 + 歌手」搜索，缓存在本地。
  在设置里选优先问哪个，问不到的会自动换另一个——两边覆盖面不一样，中文歌网易云全，欧美和冷门曲 LRCLIB 更全。

## 运行

双击 `dist\Lyric.exe`。无控制台窗口，图标出现在托盘。

源码运行：

```
pip install -r requirements.txt
pythonw lyric.py
```

## 操作

| 位置 | 操作 | 效果 |
| --- | --- | --- |
| 托盘图标 | 左键 | 打开设置程序 |
| 托盘图标 | 右键 | 显示 / 隐藏歌词、退出 |
| 歌词栏 | 左键拖动 | 在任务栏里左右平移（垂直方向固定居中，和搜索框同一条线） |
| 歌词栏 | 右键 | 设置、隐藏歌词、锁定位置、重置位置、退出 |

## 设置在哪

设置是**另一个程序**：`..\Lyric setting\LyricSetting.exe`。

两者通过 `%LOCALAPPDATA%\taskbar-lyric\config.json` 通信。本程序每 100ms 检查这个文件的
修改时间，一变就重读并应用——所以设置里拖滑块能立刻看到效果，两个程序也互不依赖。

## 自检

```
python lyric.py --selftest
```

校验 LRC 解析，并打印一次当前 SMTC 读取结果——用来确认播放器有没有把歌曲信息上报给系统。

## 两个必须知道的实现约束

1. **窗口必须保持 `WS_EX_LAYERED`。** 没有分层样式的 GDI 子窗口会被任务栏的
   DirectComposition(XAML) 层整个盖住：窗口 `visible=1`、位置也对，但**一个像素都不显示**。
   Tk 在 `-alpha` 恰好等于 1.0 时会摘掉这个样式，所以代码让 Tk 的 alpha 始终停在 0.99 以下，
   真实不透明度由 `ensure_layered()` 自己设。
2. **圆角只能自己切。** DWM 的圆角属性对任务栏子窗口返回 `E_HANDLE`（实测 `0x80070006`），
   所以歌词条用 `SetWindowRgn` 硬切——代价是边缘没有抗锯齿。

## 已知限制

- 仅主显示器；位置记在 `%LOCALAPPDATA%\taskbar-lyric\config.json`。
- explorer 重启（任务栏重建）会连带销毁作为子窗口的歌词栏，需要重启本程序。
