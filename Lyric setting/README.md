# Lyric setting

任务栏歌词的**设置程序**，Material 3 Expressive 风格（无边框窗口 + 28px 大圆角卡片 + 胶囊按钮 + 开关）。

## 运行

双击 `dist\LyricSetting.exe`。

源码运行：

```
pip install -r requirements.txt
python setting.py
```

## 它只做一件事

编辑 `%LOCALAPPDATA%\taskbar-lyric\config.json`。

歌词程序（`..\Lyric\dist\Lyric.exe`）监听这个文件，所以滑块拖动的效果是**实时**的，不用重启。

### 外观

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 字号 | 16 | |
| 不透明度 | 0.82 | |
| 宽度占比 | 0.6 | 占屏幕宽度的比例 |
| 高度 | 30 | 实测 Win11 任务栏元素都是 30px 高 |
| 圆角 | 10 | 实测搜索框圆角约 10px |

### 颜色

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 歌词颜色 | `#f2f2f7` | 点右边的色块打开系统取色器 |
| 背景颜色 | `#0d0d12` | 同上；鼠标移到歌词条上时会自动往对比方向微调一档 |

## 布局

窗口是无边框的，右下角有个小方块可以拖动缩放。卡片会跟着窗口比例重排：

- **窗口比高度宽** → 分两列，卡片按高度摊匀（外观一列，颜色 + 行为一列）
- **窗口比高度高** → 收回一列

内容放不下时窗口会自动长高，不会把卡片截掉。

### 行为

- **镶嵌到任务栏**：关掉就退回「浮在最上层的独立条」，两种模式的位置分开记。
- **锁定位置**：锁上之后拖动无效，防止误拖。
- **开机自启**：注册的是**歌词程序**（`..\Lyric\dist\Lyric.exe`），不是本程序——
  设置只在需要时手动打开。

## 一个细节

写入是**合并式**的：每次都先重读文件、只改自己那一项再写回。
所以设置开着的时候，歌词程序刚更新的位置（比如你拖了一下歌词条）不会被覆盖掉。

## 打包

`build.bat` 里必须带 `--collect-all customtkinter`——主题资源没打进去的话，
平时看着正常，一打开设置就崩。
